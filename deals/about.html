About

outdeals started as a simple idea: no ads, no affiliate cuts, no ranking algorithm. Brands and deal hunters outbid each other to rank #1 — that's it.

One board, four retailers

Everything files into a single leaderboard. An Amazon lightning deal, a Target clearance and a Walmart rollback all compete for the same #1 spot, because a shopper scanning for something worth buying does not care which logo is on it.

What the retailer does decide is context, so every listing carries its board as a tag — and its rank within that board next to it. A deal showing Target #1 at overall #7 is the best Target deal on the site even though six other deals outbid it. The tabs above the board filter to one retailer without renumbering anything: the ranks you see are always the real, global ones.

How the money works

A bid is a one-time payment for a position, not a subscription and not a cut of your sales. Raise your own listing and you pay only the difference between your old bid and your new one. Get outranked and your bid stays where it is until you decide to raise it — that is the whole business model, and there is nothing else behind it.

Payments run through Stripe Checkout. A bid is held pending while you are on the payment page and only joins the board once the charge is confirmed, so nothing ranks that was not paid for. If the same deal is listed or raised by someone else while you are paying, your payment is refunded in full instead of buying a spot you did not agree to.

Running it yourself

The board is two pieces: a static front end (this page) and an API server that owns submissions, ranking and payments. Both share one rules engine, so they can never disagree about what a bid buys.

Served without a server behind it — as on GitHub Pages — the page falls back to demo mode: the seeded board plus your own bids, kept in localStorage, with a checkout that takes no money. Point deals/config.js at a deployed API and the same page becomes the real thing. The server's README covers deployment, environment variables and the Stripe webhook.

Read the rules for exactly how ranking, raises, refunds and removals work.
